# GitHub Auto Translator

GitHub 自动翻译浏览器扩展，默认将可见文本翻译为简体中文，并支持原文/译文切换。

## 安装

1. 下载或克隆本仓库。
2. 打开 `chrome://extensions` 或 Edge 的扩展页。
3. 开启“开发者模式”。
4. 选择“加载已解压的扩展程序”，选中本仓库目录。
5. 打开 GitHub 页面测试。

## 功能

- 自动检测来源语言。
- 支持简体中文、繁体中文、英文、日语、韩语等目标语言。
- 跳过 `code`、`pre`、脚本、样式和 SVG。
- 右下角按钮切换原文/译文。
- 按 Argos、Google、MyMemory、LibreTranslate 顺序自动兜底。

## 测试

本仓库提供最小语法检查命令：

```bash
npm test
```

也可以直接在浏览器扩展页加载目录，检查扩展是否成功启用。

## 注意事项

公开翻译接口可能受到网络、频率和跨域策略影响。生产使用建议配置自己的翻译代理或自托管 LibreTranslate/Argos 服务。

当前版本保留文本节点中的标签边界，不处理代码内容；复杂 Markdown 结构仍建议后续采用服务端批量翻译。
